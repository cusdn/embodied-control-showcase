# Disclosure boundaries

This is an intentionally limited presentation snapshot. Public content is limited to the listed documents, authored diagrams, aggregate metrics and selected rendered simulation media.

Excluded: research implementation, planner/trainer scripts, learned weights, checkpoints, raw datasets/trajectories, experiment logs, private infrastructure, credentials, enterprise material and original Git history. This repository must start with fresh history; never mirror or fork the private source repository for publication.

Public numbers and videos reveal selected experimental findings, including negative outcomes. Their publication is a deliberate disclosure requiring owner approval, not a claim that all unpublished research is safe to release. No future update is automatically authorized.
